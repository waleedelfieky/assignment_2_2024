# ROS2 Action Client Example

This repository contains a basic example of a ROS1 action client implemented in Python. The goal is to demonstrate how to create and run an action client within a ROS1 environment using a Jupyter notebook.

## 📂 Added File

The only file added in this branch is a Jupyter notebook:

📁 notebooks/
└── action_client.ipynb


You can find the notebook inside the `notebooks/` directory. It contains all the necessary code and comments to help understand the structure and flow of a ROS2 action client.

## 🧪 Usage

To use the notebook:

1. Make sure your ROS2 environment is properly set up.
2. Launch JupyterLab or Jupyter Notebook inside a ROS1-ready terminal.
3. Open the `action_client.ipynb` file located in the `notebooks/` folder.
4. run the lanuch file
4. Follow the instructions in the notebook to run the client.

## 🔧 Requirements

- ROS1
- Jupyter (`pip install jupyterlab`)
- ipywidgets


## 📝 Notes

- Ensure that the corresponding ROS1 action server is running before executing the action client cells in the notebook
